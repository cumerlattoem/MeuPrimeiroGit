## Questionário

### 1. Qual é a diferença entre Working Directory, Staging Area e Repository?

Working Directory é o local onde os arquivos são criados e modificados.

Staging Area é a área onde colocamos as alterações que queremos incluir no próximo commit.

Repository é onde ficam registrados os commits e o histórico do projeto.

### 2. Qual é a diferença entre git commit e git push?

O git commit registra as alterações no repositório local.

O git push envia os commits do computador para o repositório remoto no GitHub.

### 3. É possível realizar vários commits antes de executar um git push?

Sim. Podemos fazer vários commits localmente e depois enviar todos para o GitHub utilizando o git push.

### 4. Por que é interessante realizar commits pequenos e descritivos?

Porque facilita entender o histórico do projeto e descobrir quais alterações foram feitas em cada etapa.

### 5. O que acontece com os commits locais quando ainda não executamos o git push?

Eles continuam armazenados no repositório local, mas ainda não foram enviados para o GitHub.

### 6. Como verificar, pelo GitHub, se os commits foram enviados corretamente?

Podemos acessar o repositório no GitHub e verificar os arquivos, a quantidade de commits e o histórico de alterações.
